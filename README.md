# Мои уроки — планер репетитора

Программа для компьютера: расписание, записи уроков, ученики и учёт заработка. Рассчитана на репетитора английского и китайского языков. Работает без интернета, все данные хранятся на вашем компьютере.

## Что умеет

- **Сегодня.** Ближайший урок с прошлой темой и домашним заданием, уроки дня, список «отметьте проведённые», доход за месяц и долги.
- **Расписание.** День, неделя и месяц. Клик по свободному времени создаёт урок, урок можно перетащить или растянуть. Есть выходные и отпуск.
- **Ученики.** Постоянное расписание задаётся один раз («Пн 16:00, Чт 16:00»). Уроки создаются сами и продлеваются на недели вперёд.
- **Записи уроков.** Тема, что прошли, новые слова, домашнее задание, заметка. Есть поиск по всем записям.
- **Оплаты и баланс.** У каждого ученика один баланс. Оплата («Принять оплату», например пакетом на 8 уроков) пополняет его, а когда вы отмечаете урок проведённым, его стоимость сразу списывается с баланса. Если денег не хватает, это долг. Разовую оплату можно отметить галочкой в самом уроке.
- **Доходы.** По месяцам и годам, по ученикам и языкам, цель на месяц, выгрузка в Excel.
- **Сообщения ученикам.** Одной кнопкой копируются напоминание, итоги урока и отчёт за месяц.
- **Телефон.** Синхронизация с iPhone через ваш хостинг, всё зашифровано. Значок на экране «Домой», работает без интернета.
- **Безопасность данных.** Программа сама делает копию каждый день в «Документы\Мои уроки\Резервные копии».

Горячие клавиши: `N` новый урок, `S` новый ученик, `Ctrl+K` поиск, `1–4` разделы, `?` справка.

## Расписание на iPhone

Программа умеет синхронизироваться с телефоном: смотреть уроки, переносить, добавлять, отмечать проведённые и принимать оплату можно с iPhone. Нужен обычный PHP-хостинг (Beget, SpaceWeb и другие), данные шифруются на ваших устройствах.

Пошаговая инструкция с нуля: [docs/HOSTING.md](docs/HOSTING.md). Нужный архив `moi-uroki-hosting-….zip` лежит в релизе рядом с установщиком.

## Установка (Windows)

1. Скачайте `Moi-uroki-Ustanovshchik-<версия>.exe` из раздела Releases или Actions на GitHub.
2. Запустите файл и нажмите «Далее». Ярлык появится на рабочем столе и в меню «Пуск».

Windows может показать предупреждение «Защитник Windows предотвратил запуск», потому что установщик не подписан сертификатом. Нажмите «Подробнее → Выполнить в любом случае».

Удаление: «Параметры → Приложения → Мои уроки». Ваши данные и копии при этом остаются.

## Без установки

Откройте `index.html` двойным кликом в Chrome или Edge. Данные при этом хранятся в браузере. Раз в пару недель сохраняйте копию в «Настройках».

## Для разработчика

```bash
npm install
npm start          # запуск в окне Electron
npm run dist       # сборка установщика в dist/ (нужен NSIS: makensis)
npm run hosting    # сборка архива для хостинга (dist/moi-uroki-hosting-….zip)
```

На GitHub установщик собирается workflow «Сборка установщика для Windows». Запустите его во вкладке Actions или создайте тег `v1.0.0`, тогда установщик прикрепится к релизу.
