# Мои уроки — планер репетитора

Программа для компьютера: расписание, записи уроков (тема, материал, новые слова, домашнее задание), ученики и учёт заработка (доход по месяцам и годам, долги, цель, выгрузка в CSV). Английский и китайский, светлая и тёмная темы.

## Как запустить

**Самый простой способ.** Откройте файл `index.html` двойным кликом (лучше в Chrome или Edge). Установка не нужна.

**Как отдельную программу Windows (.exe).**
1. На GitHub откройте вкладку **Actions → «Сборка программы для Windows» → Run workflow**.
2. Когда сборка закончится, скачайте архив `Moi-uroki-Windows` из раздела Artifacts. Внутри будут установщик и portable-версия.

Если на компьютере есть Node.js, программу можно собрать самому: `npm install`, затем `npm start` (запуск) или `npm run dist` (сборка .exe).

## Где хранятся данные

Данные лежат на вашем компьютере, на сервер ничего не отправляется. Раз в неделю-две нажимайте **Настройки → Скачать копию**. Файл копии можно восстановить на любом компьютере.

В браузере данные привязаны к файлу и браузеру. Если вы откроете приложение в другом браузере или из другой папки, оно покажет пустое. Для постоянной работы лучше установить программу (.exe).
